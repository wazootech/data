# Data's agent file

`data.af` is the generated [Agent File](https://github.com/letta-ai/agent-file) declaration of
Data's agent layer. It is produced from source and never hand-edited.

It is generated by `scripts/export-agent-file.ts` in
[wazootech/computer](https://github.com/wazootech/computer), from Data's authored source at
`agents/data/agent/` in that repository, and published here because this repository is Data's
public artifact home:

```bash
git clone https://github.com/wazootech/computer
cd computer
pnpm install
pnpm run export:data-agent-file
```

Data has no eve runtime yet, so the projection runs in source mode: `instructions.md` is the
prompt, and the declaration lists the GitHub tools Data may call by name. Descriptions and the
read/write class are resolved from the installed `@github-tools/sdk` declarations, so this file
cannot drift from the tool surface it names. The runtime split that gives Data a live eve agent is
[wazootech/computer#72](https://github.com/wazootech/computer/issues/72); the format decision is
[wazootech/computer#73](https://github.com/wazootech/computer/issues/73).

Rules for this directory:

- `data.af` is a projection of Data's source, never the source of truth. Edit
  `agents/data/agent/` in `wazootech/computer`, regenerate, and copy the result here.
- Do not hand-edit `data.af`. CI in `wazootech/computer` fails when the committed file and a
  fresh regeneration disagree.
- A block whose content is private is excluded by the declaration's allowlist rather than
  redacted into the export. This repository is public, so the export must never carry secrets,
  customer data, or internal-only operational detail. The exported file carries five block
  declarations, two with values (`persona`, `scope`) and three schema-only (`support_lessons`,
  `corrections`, `escalation_log`), each stating why it stays private.
