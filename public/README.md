# Public artifacts

Shareable material for developers, in four categories:

- **`guides/`** — reference material: how a subsystem works, how to reproduce a result.
- **`field-notes/`** — short observations from real investigations: what was tried, what held up.
- **`experiments/`** — bounded tests run to answer one question, with the raw result.
- **`challenges/`** — open problems handed to readers, with the reproduction that motivates them.

A piece belongs here only when its evidence is solid and it is safe to publish. Supporting code
lives in `demos/`; rough working material stays in `notes/`.
