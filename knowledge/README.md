# Knowledge

Durable developer-support knowledge: the answers that held up, the ones that did
not, and the evidence for both. This directory is a house, not a log — write
something here when it will still be true and still be useful next quarter.

Suggested shape, not a schema:

- `lessons/` — recurring questions and the answer that survived review.
- `reproductions/` — minimal cases that demonstrate a real behavior or a real bug,
  written so somebody else can run them.
- `gotchas/` — traps that cost time, with the correct form next to the wrong one.

Rules that keep this worth reading:

- Cite the source: repository, path, and line numbers. An answer a reader cannot
  re-derive is a rumor.
- Separate what was verified from what was assumed. Say which is which.
- No secrets, no private customer data, no unreviewed claims about unreleased work.
- Corrections are welcome and belong next to the thing they correct, not in a
  separate apology file.
