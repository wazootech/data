# Skills

Procedures Data follows, in the Agent Skills shape used elsewhere in the
organization: one directory per skill with a `SKILL.md` (frontmatter `name` and
`description`, then the instructions), plus `scripts/`, `references/`, and `assets/`
when the skill needs them.

A skill is worth writing here when the same investigation happens twice: the steps
to verify a claim against a repository, the checks that make an answer trustworthy,
the handoff format that Computer can act on.
